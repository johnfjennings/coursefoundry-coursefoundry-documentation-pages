Welcome

1. Introduction

What is CourseFoundry?

CourseFoundry is a Markdown-native course authoring platform with a built-in AI assistant (AI Forge). It is designed for people who know their subject deeply and want a professional, structured way to turn that knowledge into a shareable course — without fighting a drag-and-drop editor or paying for bloated enterprise software.

You write in plain Markdown (specifically Quarto Markdown), your files are structured like a real project, and AI Forge handles the heavy lifting: generating outlines, drafting lessons, building slide decks, creating assessments, and reviewing your content.

Who It’s For

CourseFoundry is built for three main types of course creator:

Persona Description Recommended Plan
Technical Trainer Freelancer, consultant, or subject matter expert creating professional development or software training Creator
Lecturer / Academic University or college educator building structured learning materials Creator or Pro
L&D Team Corporate learning and development team running onboarding, compliance, or upskilling programmes Pro or Enterprise

If you’ve ever felt that consumer platforms like Teachable were built for influencers rather than educators, or that institutional tools like Moodle were too complex for individual use, CourseFoundry sits in the space between.

Key Concepts

Before diving in, it helps to understand a few terms used throughout this documentation.

Quarto Markdown (.qmd) CourseFoundry courses are written in Quarto Markdown — a plain-text format that extends standard Markdown with academic and technical features like callout blocks, cross-references, and presentation output. Files use the .qmd extension but are otherwise identical to .md files in most respects. You do not need to install Quarto to use CourseFoundry — the platform handles rendering.

Course A course is a container for your content. It has a title, description, status (draft or published), and a collection of files that make up the lessons, structure, and supporting material.

Course Files Every piece of content inside a course is stored as a file — lessons, the course structure (_quarto.yml), and any supporting documents. Files are organised into modules (folders) within the course. All files are stored securely and privately until you publish.

_quarto.yml This is the course’s configuration and navigation file. It defines the course type (website), a docked collapsible sidebar with nested week/module sections, and settings such as page navigation, reader mode, and search. When you use a template, this file is generated for you. CourseFoundry automatically regenerates the sidebar whenever you toggle a folder’s visibility (see Staged Publishing). If you add new files and want them to appear in the sidebar immediately — without toggling visibility — you can edit _quarto.yml directly and add the file path under website.sidebar.contents.

AI Credits AI credits are consumed each time you use an AI Forge workflow. Different plans include different monthly credit allowances. Credits reset on the first of each month. See Plans & Billing for details.

Slug A slug is the URL-friendly version of your course title, used in the public URL for your course (e.g. coursefoundry.com/learn/intro-to-smart-manufacturing). It is generated automatically from the title and cannot be changed after course creation.
