4. The Editor

The editor at /courses/[courseId]/editor is where you spend most of your time in CourseFoundry. It has three main areas: the file tree on the left, the Monaco editor in the centre, and the right panel with four tabs.

Layout Overview

The file tree and right panel can each be collapsed with the toggle buttons in the toolbar to give you more writing space.

Editor Toolbar

The toolbar at the top of the editor contains:

Button Action
Course title (left) Returns to the dashboard
Globe / GlobeLock icon Publish or unpublish the course
Panel left toggle Show / hide the file tree
Panel right toggle Show / hide the right panel

The File Tree

The file tree shows all files in your course. Click any file to open it in the editor.

Creating a file Click the + button at the top of the file tree. Enter a file path, including the folder structure if needed (e.g. modules/04-advanced/01-lesson.qmd). The file is created immediately and opened in the editor.

Tip: New lesson files are picked up automatically the next time you toggle a folder’s visibility. If you want to add a file to the published sidebar immediately without changing visibility, open _quarto.yml and add it under website.sidebar.contents.

Renaming a file Hover over a file in the tree and click the rename icon. Enter the new name and press Enter.

Deleting a file Hover over a file and click the delete icon. Confirm deletion in the prompt. File deletion is permanent.

Hiding a folder (Staged Publishing) Hover over any folder in the file tree to reveal action icons. Click the Eye icon to hide that folder — all files inside it are excluded from _quarto.yml when the course is published to GitHub Pages. The folder dims to indicate it is hidden. Click the Eye-off icon to make it visible again. See Staged Publishing for the full workflow.

File order Files appear in the sidebar in the order defined by _quarto.yml. The file tree reflects folder and file name order. Use numeric prefixes (01-, 02-) to control sort order.

Writing in Quarto Markdown

All lesson files use the .qmd extension and follow standard Markdown syntax with some Quarto-specific additions.

YAML frontmatter Every .qmd file should start with a YAML frontmatter block:

---
title: "Your Lesson Title"
---

This sets the title shown in navigation and as the page heading.

Headings Use ## for main sections and ### for sub-sections. The frontmatter title acts as the H1, so start your body content at H2.

Code blocks Fenced code blocks with a language tag get syntax highlighting:

```python
def hello():
    print("Hello, world!")
```

Callout blocks Quarto callouts draw attention to important content:

::: {.callout-tip}
## Tip Title
Helpful suggestion here.
:::

::: {.callout-note}
Something worth noting.
:::

::: {.callout-warning}
A caution or warning.
:::

::: {.callout-important}
Critical information.
:::

Collapsible callouts (useful for answer keys):

::: {.callout-tip collapse="true"}
## Answer
The correct answer is B, because...
:::

Autosave

The editor saves your work automatically after 1.5 seconds of inactivity. A subtle indicator in the toolbar shows the save status. There is no manual save button — just write, and your content is preserved.

Note: Autosave writes to the CourseFoundry database. This is separate from GitHub. To save a versioned snapshot to GitHub, use the Git panel (see GitHub Integration).

The Preview Pane

Click the Preview tab in the right panel to see a rendered version of the file currently open in the editor. The preview updates as you type (with a short debounce delay).

Quarto-specific features rendered in preview: - Callout blocks (.callout-tip, .callout-note, .callout-warning, .callout-important) - Standard Markdown (headings, lists, tables, code blocks, bold, italic)

Note: The preview is a live approximation. The final published output may differ slightly in styling. Full Quarto rendering (cross-references, bibliographies, etc.) is not processed server-side in this version.

The Media Panel

Click the Media tab in the right panel to manage visual assets for your course.

Images tab

Upload image files (PNG, JPG, GIF, SVG, WebP) directly from your computer. Uploaded images are stored in Supabase Storage and served via a CDN. Click any uploaded image to insert a Markdown image tag at your cursor position:

![Image description](https://cdn.../your-image.png)

Placeholders tab

Placeholder images let you mark where a real image will go while you focus on writing content. They are generated as styled SVG files with descriptive text baked in, so your course structure is complete even before photography, diagrams, or screenshots are ready.

To create a placeholder: 1. Select a Content Type: Image, Video, Diagram, Screenshot, or Icon — each uses a distinct colour scheme 2. Select an Aspect Ratio: 16×9, 1×1, 4×3, Portrait, or Banner 3. Enter a Label (the image name shown on the placeholder) and a Description (brief notes about what should go here) 4. Optionally expand Advanced to add an AI prompt (for AI image generation later) or a designer brief 5. Click Create & Insert — the placeholder SVG is uploaded and a Markdown image tag is inserted at your cursor

Existing placeholders are listed below the creation form with a thumbnail. Click the Edit icon on any placeholder to update its label, description, or briefs — the SVG is regenerated in place and the Markdown reference in your files stays valid.
