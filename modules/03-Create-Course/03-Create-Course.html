3. Creating a Course

The New Course Wizard

The course creation wizard walks you through three steps before opening the editor.

Step 1 — Choose a Template

Five templates are available:

Template Best For
Blank Maximum control; minimal scaffolding
Technical Tutorial Step-by-step guides with optional prerequisites and troubleshooting
Academic Course Multi-module, lecture-style courses with optional assessments
Workshop Hands-on sessions with exercises and an optional capstone project
Semester Course University-style semester courses with weekly activity plans, assessments, and optional BibTeX references

Click a template card to select it, then click Next.

Step 2 — Customise Your Course

This step adapts to the template you selected. Most templates share two common fields:

Field Description Default
Target Audience Beginner / Intermediate / Advanced — shown on the course landing page Beginner
Estimated Duration Free text, e.g. “3 hours” or “6 weeks” — shown on the landing page if set (blank)

Note: The Semester Course template does not show Target Audience (it defaults to Beginner automatically) as the audience is implicitly defined by the programme level.

Template-specific options are shown below.

Technical Tutorial

Field Description Default Range
Number of Steps How many step files to generate 3 2–8
Primary Language / Tool Code block language tag in step files bash Any (python, javascript, etc.)
Include Prerequisites section? Generates a prerequisites file Yes Yes / No
Include Troubleshooting section? Generates a troubleshooting file Yes Yes / No

Academic Course

Field Description Default Range
Number of Modules How many module folders to generate 3 2–8
Lessons per Module Lesson files generated in each module 2 1–5
Delivery Mode Self-paced / Scheduled / Blended — shown on landing page Self-paced —
Include assessments per module? Generates an assessment.qmd at the end of each module Yes Yes / No

Workshop

Field Description Default Range
Number of Exercises Exercise files to generate 3 1–6
Workshop Format Half-day / Full-day / Multi-day — shown on landing page Full-day —
Delivery In-person / Virtual / Hybrid — shown on landing page In-person —
Include Capstone Project? Generates a capstone project file Yes Yes / No
Include Reflection & Next Steps? Generates a reflection file Yes Yes / No

Semester Course

Field Description Default Range
Number of Weeks How many week folders to generate 12 1–52
Lecture hours/week Weekly lecture contact hours 2 0+
Tutorial hours/week Weekly tutorial contact hours 1 0+
Self-Study hours/week Weekly self-study hours 3 0+
Homework hours/week Weekly homework hours 2 0+
Pre-Reads hours/week Weekly pre-reading hours 1 0+
Practical / Laboratory hours/week Optional practical or lab contact hours 0 0+
Number of Assessments Standalone assessment files to generate 0 0–12
Include References folder? Generates references/references.bib with example BibTeX entries Yes Yes / No

Step 3 — Name Your Course

Enter a Course Title (required). This becomes the heading on your course landing page and is used to generate the URL slug.

Add an optional Description — a short summary shown on the public course card and landing page.

Click Create Course. The editor opens immediately with your scaffolded files.

Note: The URL slug is derived from the title at creation time and cannot be changed afterwards. Choose your title carefully before creating.

Template File Structures

After course creation, each template produces the following file structure. All templates include a README.md in the root — a GitHub-style readme with course metadata, learning outcomes, getting started instructions, and CourseFoundry branding.
