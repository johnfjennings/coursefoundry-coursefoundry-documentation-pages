5. AI Forge

AI Forge is the AI copilot built into the editor. It helps you generate, improve, and review course content without leaving the editor.

What is AI Forge?

AI Forge is a set of purpose-built AI workflows and a free-form chat assistant, all powered by Claude (Anthropic). Each workflow is designed around a specific authoring task — generating an outline, drafting a lesson, building an assessment — and produces output formatted for Quarto Markdown.

Open AI Forge by clicking the Forge tab in the right panel.

AI Credits

Every AI Forge action consumes credits from your monthly allowance.

Plan Credits / Month
Starter 50 (6-month trial, then 0)
Creator 500
Pro 2,000
Enterprise 100,000

Credits are deducted when you click Generate or send a chat message. If generation fails (e.g. due to a network error), the credit is still counted — the AI call was made.

Your remaining credits are shown in the dashboard stats panel and in Settings. Credits reset on the 1st of each month.

Starter trial: New accounts on the Starter plan receive 50 free credits for the first 6 months. After the trial period, the Starter plan remains free forever but AI credits are set to 0. Upgrade to Creator or Pro to continue using AI Forge.

Workflow Reference

Outline Generator

What it does: Generates a complete _quarto.yml course structure plus a brief description of each module and lesson.

When to use it: At the start of a new course, before you’ve written any content. Use it to rapidly scaffold a logical, pedagogically sound structure.

How to use it: 1. Open _quarto.yml in the editor (so the result can be copied in easily) 2. In the Forge tab, select Generate Outline 3. The workflow reads your course title and description automatically 4. Click Generate 5. Review the output and copy it into _quarto.yml, or use Insert to replace the current file content

Output: A YAML Quarto book configuration with module/lesson hierarchy, plus short lesson descriptions.

Tips: - Write a detailed course description before generating — more context produces a better outline - The outline is a starting point; edit the module and lesson names to match your specific content - After editing _quarto.yml, create the corresponding .qmd files in the file tree

Lesson Drafter

What it does: Writes a full lesson in Quarto Markdown, including YAML frontmatter, section headings, practical examples, callout blocks, and a summary.

When to use it: When you need a first draft of a lesson quickly. The draft will need editing but gives you a solid structure to build on.

How to use it: 1. Open the lesson file you want to draft in the editor 2. In the Forge tab, select Draft Lesson 3. The workflow reads your course title, the current lesson title (from the file’s frontmatter), the _quarto.yml outline, and adjacent lessons for context 4. Click Generate 5. Review the output and click Insert to replace the current file content, or copy manually

Output: A complete .qmd lesson — 800 to 1,500 words, structured with headings, practical examples, and callouts.

Tips: - The more complete your _quarto.yml is, the better the draft — it uses the full outline as context - Draft lessons in order; each draft reads adjacent lesson content for continuity - Always review and edit the draft — AI output requires a human pass for accuracy and voice

Slide Generator

What it does: Converts the content of a lesson file into a Reveal.js slide deck in Quarto format (.qmd with format: revealjs).

When to use it: When you need a presentation version of a lesson — for live delivery, recording, or supplementary material.

How to use it: 1. Open the lesson file you want to convert 2. In the Forge tab, select Generate Slides 3. The workflow reads the current file content automatically 4. Click Generate 5. Create a new file for the slides (e.g. modules/01-introduction/01-slides.qmd) and paste or insert the output

Output: A complete Reveal.js .qmd presentation with: - Title slide, overview slide, content slides, summary slide - Speaker notes in ::: {.notes} blocks - Maximum 6 content lines per slide - Incremental reveals where appropriate

Tips: - Run the Lesson Drafter first, then Slide Generator — you get both a lesson and slides from one workflow - Slide decks should be stored as separate files, not as replacements for lesson files - Speaker notes are a good place to add context that doesn’t fit on the slide

Assessment Builder

What it does: Creates a quiz with multiple choice questions, short answer questions, and practical exercises based on a lesson’s content.

When to use it: After finishing a lesson, to create a formative or summative assessment.

How to use it: 1. Open the lesson file you want to assess 2. In the Forge tab, select Build Assessment 3. The workflow reads the current file content automatically 4. Click Generate 5. Create a new file (e.g. modules/01-introduction/assessment.qmd) and paste or insert the output

Output: A .qmd assessment with: - 5–8 questions - Mixed question types (multiple choice, short answer, practical scenario) - Questions ordered from basic recall to applied understanding - Answer keys in collapsible callout blocks

Tips: - Review all answers carefully — AI-generated answer keys can contain errors - Remove or rewrite questions that are ambiguous or too easy - The assessment file should be added to _quarto.yml if you want it visible to learners

Content Reviewer

What it does: Reviews a lesson against five dimensions and provides specific, actionable feedback.

Review dimensions: 1. Learning Design — Are objectives clear? Does content build progressively? 2. Clarity & Readability — Is the writing clear? Is jargon explained? 3. Accessibility — Are images described? Are headings structured? 4. Completeness — Are all outline topics covered? Are there gaps? 5. Technical Accuracy — Are code examples correct? Are claims accurate?

When to use it: After finishing a first draft of a lesson, before publishing.

How to use it: 1. Open the lesson you want reviewed 2. In the Forge tab, select Review Content 3. Click Generate 4. Read the review in the output area — each finding is labelled with severity (🔴 Critical / 🟡 Suggestion / 🟢 Praise) and dimension

Output: A structured review with a score out of 5 for each dimension, individual findings with severity and detail, and a top-3 priority improvements list.

Tips: - Treat 🔴 Critical findings as must-fix before publishing - Run the reviewer again after making revisions — scores improve iteratively - The reviewer works best on longer, more complete lessons

Import Helper

What it does: Takes raw, unstructured content — slide notes, a PDF transcript, rough notes, a blog post — and restructures it into a polished Quarto Markdown lesson.

When to use it: When you have existing material you want to convert into a proper lesson without starting from scratch.

How to use it: 1. In the Forge tab, click the Import tab 2. Paste your raw content into the text area 3. Enter a lesson title 4. Click Structure with AI 5. Review the output. Click Insert to replace the current file, or Create as New File to save it as a new lesson

What it preserves: All factual content, examples, domain terminology, and code snippets from the original.

What it improves: Structure (logical sections), Markdown formatting, callout blocks for key points, a Summary section.

Tips: - Works well with: slide exports, meeting notes, existing blog posts, lecture transcripts, Word documents (paste the plain text) - The longer and richer the source material, the better the output - Always review code blocks in the output — they may need language tags or corrections

Chat Mode

What it does: A free-form conversational assistant with full awareness of your course context. Ask it anything about your course, request specific edits, ask for examples, or have it write a section in a particular style.

When to use it: For anything that doesn’t fit the structured workflows — brainstorming, getting unstuck, asking “how should I explain X to a beginner?”, requesting a specific paragraph, or iterating on a draft.

How to use it: 1. In the Forge tab, click the Chat tab 2. Type your message and press Enter (or click Send) 3. The assistant responds in the chat. Each response has Copy and Insert buttons 4. Continue the conversation — the assistant remembers the full message history for the session 5. Click Clear to start a fresh conversation

What the assistant knows: - Your course title and description - The first 3,000 characters of the file currently open in the editor

Tips: - If asking for Markdown content, say “in Quarto Markdown” — it will use the correct callout syntax - For long edits, use Insert to push content directly into the editor, then tidy up - The chat is session-based; it resets when you reload the page or switch courses - Each message sent costs 1 credit

Tips for Best AI Results

  • Write a good course description before generating — it’s passed as context to every workflow
  • Keep _quarto.yml up to date — the outline is used by the Lesson Drafter and Reviewer
  • Use workflows in sequence — Outline → Lesson Draft → Slide Generator → Assessment Builder → Content Reviewer mirrors the natural authoring flow
  • Edit every output — AI Forge produces a solid first draft; a human review pass is always needed for accuracy, voice, and nuance
  • One lesson at a time — workflows operate on the currently open file; keep the relevant lesson open before clicking Generate
