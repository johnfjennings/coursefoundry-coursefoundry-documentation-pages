2. Getting Started

Creating an Account

Go to coursefoundry.com and click Sign Up. You can sign up with:

  • Email and password — enter your email and choose a password
  • GitHub — authorises via GitHub OAuth (recommended if you plan to use GitHub integration)
  • Google — authorises via Google OAuth

After signing up, you will be redirected to your dashboard.

Beta access: During the beta period, accounts must be approved before accessing the authoring tools. If you see a waiting screen after signing up, your account is pending beta activation.

Dashboard Orientation

The dashboard at /dashboard is your home base. From here you can:

  • See all your courses in a card grid, sorted by most recently edited
  • Create a new course with the New Course button
  • Duplicate or delete existing courses
  • View your AI credit usage for the current month
  • Access Settings for billing and GitHub connection

Each course card shows: - Status badge — Draft (grey) or Published (green) - Community badges — Official, In Community, Pending Review, or Rejected (if submitted for the community catalog) - Last edited date - View button (published courses only) — opens the public learner page - Duplicate icon — creates a copy of the course - Delete icon — opens a confirmation modal before deleting

Quick Start: Your First Course in 5 Minutes

  1. Click New Course on the dashboard
  2. Step 1 — Choose a template. Select Academic Course if you’re building a structured multi-module course, or Technical Tutorial for a step-by-step guide. For maximum control, choose Blank.
  3. Step 2 — Customise. Set your target audience, estimated duration, number of modules/lessons, and any optional sections (assessments, prerequisites, etc.).
  4. Step 3 — Name it. Enter a course title and optional description. Click Create Course.
  5. The editor opens with a scaffolded file structure. Your _quarto.yml and lesson files are ready to edit.
  6. Click on any lesson file in the file tree. Start writing.
  7. Use AI Forge → Lesson Drafter to generate a first draft of the selected lesson.
  8. When you’re ready, click the globe icon in the toolbar to publish.
